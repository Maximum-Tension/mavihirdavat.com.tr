# Clone

For the full source (including documentation), clone the repository:

```sh
git clone --depth 1 "git@github.com:Maximum-Tension/mavihirdavat.com.tr.git"
```

`--depth 1` clones only the latest snapshot and skips full history.

### Clone as HTTPS

```sh
git clone --depth 1 "https://github.com/Maximum-Tension/mavihirdavat.com.tr.git"
```

### Clone as SSH

```sh
git clone --depth 1 "git@github.com:Maximum-Tension/mavihirdavat.com.tr.git"
```
